Manaslu High-Altitude Forecast Alerter

2026

Automated forecast pipeline for Mt Manaslu (8,163 m): pulls Open-Meteo API data, vertically interpolates it onto six climbing bands via geopotential height, checks safety thresholds, and ships twice-daily digests + real-time danger alerts over email / Telegram / SMS. GitHub Actions-scheduled, SQLite-deduplicated, 99 offline tests.

Phi-3 Finance LLM — Fine-Tune & Deploy

2026

Fine-tuned Microsoft's Phi-3 Mini (3.8B) on a purpose-built 400-pair personal-finance Q&A set using QLoRA (4-bit, LoRA rank-16). Merged the adapter into a standalone 7.6 GB model, containerised it with Docker + FastAPI, and deployed it on GCP Vertex AI behind a multi-turn Gradio chat UI — taken end-to-end from dataset to a live cloud endpoint over 11 deployment iterations.
